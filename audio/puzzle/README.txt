PUZZLE MUSIC / পাজলের গান

1. Put your song files (mp3) in this folder (audio/puzzle/).  
   গানের ফাইলগুলো (mp3) এই ফোল্ডারে রাখুন।
2. Open songs.js and add each file name to the list, for example:  
   songs.js খুলে প্রতিটি গানের নাম তালিকায় যোগ করুন, যেমন:
       'audio/puzzle/my-song.mp3',
3. PLAY চাপলে তালিকা থেকে একটা গান এলোমেলোভাবে বেজে উঠবে।
